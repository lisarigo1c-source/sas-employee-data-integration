
# Data Description

This project uses three synthetic employee datasets:

- **Employee Information:** Employee IDs, departments and job titles.
- **Address Information:** Residential address details associated with each employee.
- **Donation Records:** Employee donations recorded across four quarters.

The datasets are merged using `Employee_ID` as the common identifier.

## Data Availability

The original datasets are not included in this repository.

The SAS script documents the data integration, processing and reporting procedures. The original data files are required to reproduce the analysis.
